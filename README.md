# Veda Technology – Security Awareness & Risk Assessment Portal

## 1. Project Overview
The Veda Security Portal is a web-based cybersecurity project developed to improve security awareness and help users identify and manage basic security risks.

## 2. Objectives
- To spread cybersecurity awareness.
- To educate users about password security and phishing attacks.
- To assess security risks.
- To maintain incident reports.
- To provide basic security recommendations.

## 3. Technologies Used
- **HTML:** Creates the structure of the website.
- **CSS:** Designs and styles the website.
- **JavaScript:** Adds interactive features.
- **Python Flask:** Provides backend functionality and API services.
- **SQLite:** Stores risk assessments and incident reports.

## 4. Main Features
1. Security Awareness
2. Password Security Checklist
3. Phishing Awareness Quiz
4. Device Security
5. Asset Inventory
6. Risk Assessment Calculator
7. Risk Dashboard
8. Incident Reporting
9. Security Recommendations

## 5. Risk Assessment
The risk score is calculated using:

**Risk Score = Likelihood × Impact**

Risk levels:
- 1–5: Low Risk
- 6–12: Medium Risk
- 13–25: High Risk

Example: Likelihood = 4 and Impact = 5.

Risk Score = 4 × 5 = 20 (High Risk).

## 6. Backend and Database
The project uses Python Flask to connect the frontend with the backend through API endpoints.

SQLite is used to store risk assessment records and incident reports.

## 7. How to Run the Project
1. Install Python.
2. Install Flask using `py -m pip install flask`.
3. Open the project folder in VS Code.
4. Run the backend using `py Backend/app.py`.
5. Open a browser.
6. Visit `http://127.0.0.1:5000`.

## 8. Conclusion
The Veda Security Portal demonstrates basic cybersecurity awareness, risk assessment, incident reporting and database integration. It helps users understand common security threats and basic risk management.
